# Амьтдын пикник

2-р ангийн хүүхдэд хуваах үйлдлийг хийж үзэх → тайлбарлах → тоон бичиглэлтэй холбох дарааллаар заах Монгол хэлтэй 3D тоглоом.

## Шууд тоглох — суулгалт, интернет, сервергүй

`dist/animal-picnic.html` файлыг Edge, Chrome, Firefox эсвэл Safari хөтөч дээр нээнэ. Бүх код, загвар, дүрслэл файл дотроо багтсан. Нэвтрэлт, хэрэглэгчийн нэр, алсын зураг, CDN шаардлагагүй. WebGL 2 дэмждэг хөтөч хэрэгтэй; дэмжихгүй үед тайлбар болон товчлуураар тоглох хувилбар гарна.

Файлын байрлалыг сольсон эсвэл өөр хөтөч ашигласан үед өмнөх ахиц өөр хадгалах орчинд үлдэж болно. Хөтөч localStorage-ийг хаасан бол тоглоом ажиллана, ахиц хадгалахгүйг мэдэгдэнэ.

## Эх кодыг ажиллуулах

Node.js 22.13+ болон npm:

```sh
npm install
npm run dev
```

Хэвлэгдсэн локал URL-ийг хөтөч дээр нээнэ. Энэ ажлын хавтсанд бэлтгэсэн зөөврийн Node.js-ийг ашиглах бол PowerShell дээр:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-game.ps1
```

Зөвхөн ажиллаж буй процессын execution policy хэрэглэнэ; төхөөрөмжийн байнгын тохиргоог өөрчлөхгүй.

```sh
npm test
npm run test:browser
npm run build
npm run preview
```

Browser тест нь Windows Edge-ийн стандарт замыг ашиглана. Өөр орчинд `PICNIC_BROWSER` хувьсагчид Chromium төрлийн хөтчийн executable зам өгнө. Тестийн өмнө `npm run dev` ажиллаж байх ёстой.

`npm run build` нь түгээх `dist/` хавтас болон шууд нээгдэх `dist/animal-picnic.html` файлыг үүсгэнэ. Веб сервер дээр байршуулах бол `dist/`-ийн агуулгыг түгээнэ; тоглоом өөрийн backend шаардахгүй.

## Агуулга

- Нэг тойргийг үзүүлдэг 4 лууван / 2 найзын эхний хичээл.
- 10 бие даан тэнцүү хуваах даалгавар.
- Эхлээд хариугаа сонгоод, хуваарилж шалгах 2 даалгавар.
- Сагсны тоог олох 4 бүлэглэх даалгавар.
- 7 ÷ 2: 3,3 → 4,3 гэж турших → нэгийг буцаах → үлдэгдлийг тайлбарлах → нэг лууван нэмэх → 8 ÷ 2 гэсэн тусгай хичээл.
- 5 ÷ 2, 8 ÷ 3, 10 ÷ 3, 9 ÷ 3 гэсэн 4 бататгах даалгавар.
- Нийт 22 даалгавар. Үлдэгдлийн бүлэг бие даасан тэнцүү хуваах нэг даалгаврыг дуусгасны дараа нээгдэнэ.
- 3 даалгаварт цэцэг, 6 даалгаварт шинэ дэвсгэр нээгдэнэ.
- Эцэг эх / багш: дуусгасан шат, тусламжтай/тусламжгүй үр дүн, давтах, баталгаажуулалттай ахиц цэвэрлэх.

## Удирдлага

Хоолыг чирэх эсвэл хоол → таваг/сагс/төв тавцан гэсэн дарааллаар товшино. Таваг хооронд шилжүүлэх, төвд буцаах боломжтой. Буруу газар буулгавал байрлал нь өөрчлөгдөхгүй. Escape сонголтыг болиулна. Товчлуурууд Tab, Enter, Space дэмжинэ. «Товчлуураар тоглох» хэсэг нь хоол бүрийн байрлалыг нэртэй товчоор харуулна.

«Шалгах» эхлээд бодит хуваарилалтыг шалгана. Дараа нь тоон хариуг сонгож дахин шалгана. Зөв хуваарилалт болон зөв тоон хариу хоёулаа шаардагдана. Алдаа гарахад хийсэн ажлыг арилгахгүй. Тусламж эхлээд санаа өгч, дараагийн даралт бүрд зөвхөн нэг хөдөлгөөн үзүүлнэ.

## Кодын бүтэц

- `src/lessons.ts` — бүх даалгаврын нэгдсэн өгөгдөл.
- `src/game.ts` — DOM/Three.js-ээс тусгаарласан reducer, шалгах логик.
- `src/storage.ts` — хувилбартай хадгалалт, эвдэрсэн өгөгдлийг сэргээх хамгаалалт.
- `src/Scene.tsx` — геометрээр бүтээсэн 3D амьтад, хоол, гэрэл, сүүдэр, pointer удирдлага.
- `src/App.tsx` — дэлгэц, хичээлийн дараалал, ахиц, тохиргоо.
- `src/speech.ts` — Монгол ярианы дэмжлэг, нэмэлт бичлэгийн холболт, дууны эффект.
- `src/webmcp.ts` — дэмждэг хөтөч дээр одоогийн талбайг зөвхөн унших нэмэлт хэрэгсэл.
- `tests/` — логик болон хөтчийн автомат шалгалтууд.
- `scripts/standalone.mjs` — бүх хөрөнгийг нэг HTML-д багтаах угсралт.

## Хамаарлууд

React, React DOM, TypeScript, Three.js, Lucide React, Vite, esbuild. Шалгалтад Node test runner, tsx, Playwright ашигласан. Яг хувилбарууд `package-lock.json`-д түгжигдсэн. Дүрс, зураг, 3D загварын алсын таталт байхгүй.

## Дуу ба хүртээмж

Дууны эффект дотоод Web Audio-оор үүснэ. Монгол хэлтэй системийн `mn`/ `mn-MN` хоолой байвал «Зааврыг дахин сонсох» товч гарна. Байхгүй бол энэ товч харагдахгүй, бичгэн заавар бүрэн үлдэнэ. Урьдчилан бичсэн Монгол дуу энэ хувилбарт ороогүй. Бичлэг нэмэх бол `src/speech.ts` дахь `mongolianRecordings`-д хичээлийн ID → файлын URL холбоно.

Төхөөрөмжийн `prefers-reduced-motion` болон тоглоомын хөдөлгөөн багасгах тохиргоог хүндэтгэнэ. Утас дээр 3D нягтралыг 1.6-аар хязгаарлаж, сүүдрийг 1024 нягтралтай, animation-ийг ойролцоогоор 30 fps ажиллуулна. Амжилтын хөдөлгөөн дараагийн алхмыг түгжихгүй.

## Шалгалт

`tests/game.test.ts` нь 6÷2, 7÷2, 8÷3, 9÷3, дутуу хуваарилалт 2,2+3, тэнцүү бус 4,3, 10 алимыг 2-оор бүлэглэх, тусгай хичээлийн 7→8 өөрчлөлт, тоон хариу, таамаг өөрчлөх, 1000 дараалсан шилжүүлэлт, буцаах/дахин эхлэх, хадгалалт болон бүх хичээл бодогдохыг шалгана.

Хөтчийн тестүүд компьютер, утасны хэмжээ, товших, чирэх, буруу газар тавих, хичээлийн бүтэн дараалал, ахиц сэргээх, гарын удирдлага, тохиргоог шалгана. Энэ нь бодит Android/iOS төхөөрөмжийн гүйцэтгэлийн хэмжилт биш. Монгол системийн дууны чанарыг хоолой суусан төхөөрөмж дээр тусад нь турших хэрэгтэй.

WebMCP хэрэгслийн гэрээ, өгөгдөл, оролтын шалгалтыг unit тестээр шалгасан. Энэ орчинд бодит WebMCP дэмждэг хөтөч холбогдоогүй тул тухайн хөтөчтэй интеграцыг баталгаажуулаагүй.
