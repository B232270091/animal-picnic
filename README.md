# Амьтдын пикник

2-р ангийн хүүхдэд хуваах үйлдлийг хийж үзэх → тайлбарлах → тоон бичиглэлтэй холбох дарааллаар заах Монгол хэлтэй 3D тоглоом.

## Онлайн тоглох

https://b232270091.github.io/animal-picnic/

## Локал хувилбар

`dist/animal-picnic.html` файлыг Edge, Chrome, Firefox эсвэл Safari хөтөч дээр нээнэ. Бүх код, загвар, дүрслэл файл дотроо багтсан. Дуут зааварт хажуугийн `audio/` хавтас дахь 52 MP3 хэрэгтэй. Нэвтрэлт, хэрэглэгчийн нэр, алсын зураг, CDN шаардлагагүй. WebGL 2 дэмждэг хөтөч хэрэгтэй; дэмжихгүй үед тайлбар болон товчлуураар тоглох хувилбар гарна.

Файлын байрлалыг сольсон эсвэл өөр хөтөч ашигласан үед өмнөх ахиц өөр хадгалах орчинд үлдэж болно. Хөтөч localStorage-ийг хаасан бол тоглоом ажиллана, ахиц хадгалахгүйг мэдэгдэнэ.

## Эх кодыг ажиллуулах

Node.js 22.13+ болон npm:

```sh
npm install
npm run dev
```

Хэвлэгдсэн локал URL-ийг хөтөч дээр нээнэ. Энэ ажлын хавтсанд бэлтгэсэн зөөврийн Node.js-ийг ашиглах бол PowerShell дээр:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-game.ps1
```

Зөвхөн ажиллаж буй процессын execution policy хэрэглэнэ; төхөөрөмжийн байнгын тохиргоог өөрчлөхгүй.

```sh
npm test
npm run test:browser
npm run build
npm run preview
```

Browser тест нь Windows Edge-ийн стандарт замыг ашиглана. Өөр орчинд `PICNIC_BROWSER` хувьсагчид Chromium төрлийн хөтчийн executable зам өгнө. Тестийн өмнө `npm run dev` ажиллаж байх ёстой.

`npm run build` нь түгээх `dist/` хавтас болон шууд нээгдэх `dist/animal-picnic.html` файлыг үүсгэнэ. Веб сервер дээр байршуулах бол `dist/`-ийн агуулгыг түгээнэ; тоглоом өөрийн backend шаардахгүй.

## Агуулга

- Нэг тойргийг үзүүлдэг 4 лууван / 2 найзын эхний хичээл.
- 10 бие даан тэнцүү хуваах даалгавар.
- Эхлээд хариугаа сонгоод, хуваарилж шалгах 2 даалгавар.
- Сагсны тоог олох 4 бүлэглэх даалгавар.
- 7 ÷ 2: 3,3 → 4,3 гэж турших → нэгийг буцаах → үлдэгдлийг тайлбарлах → нэг лууван нэмэх → 8 ÷ 2 гэсэн тусгай хичээл.
- 5 ÷ 2, 8 ÷ 3, 10 ÷ 3, 9 ÷ 3 гэсэн 4 бататгах даалгавар.
- Ойн хүргэлтийн 5 даалгавар: 6÷2, 9÷3, 12÷3, 7÷2, 10÷3. Алим → байшин сонгоход үнэг авч, зөөж, сагсанд тавина.
- Ойн өртөөний 5 даалгавар: 6÷2, 9÷3, 7÷2, 8÷3, 12÷3. Амьтан → тодорхой суудал сонгоно. Зөвхөн дүүрсэн вагоныг бүтэн бүлэг гэж тоолно.
- 12÷3-ыг хоёр орчноор харьцуулах 2 холимог даалгавар. «4 алим / байшин» ба «4 дүүрсэн вагон» гэсэн нэгжийг ялгана.
- Нийт 34 даалгавар, гурван том зурагтай тоглох бүс. Хуучин 22 хичээлийн ID болон ахиц хадгалагдсан. Дараалал: хамтдаа → бие даан → хүргэлт → бүлэглэлт → үлдэгдэл → холимог давтлага.
- Үлдэгдлийн бүлэг бие даасан тэнцүү хуваах нэг даалгаврыг дуусгасны дараа нээгдэнэ.
- 3 даалгаварт цэцэг, 6 даалгаварт шинэ дэвсгэр, 9 даалгаварт вагон болон сагсны өнгө нээгдэнэ.
- Эцэг эх / багш: дуусгасан шат, тусламжтай/тусламжгүй үр дүн, давтах, баталгаажуулалттай ахиц цэвэрлэх.

## Удирдлага

Хоолыг чирэх эсвэл хоол → таваг/сагс/төв тавцан гэсэн дарааллаар товшино. Таваг хооронд шилжүүлэх, төвд буцаах боломжтой. Буруу газар буулгавал байрлал нь өөрчлөгдөхгүй. Escape сонголтыг болиулна. Товчлуурууд Tab, Enter, Space дэмжинэ. «Товчлуураар тоглох» хэсэг нь хоол бүрийн байрлалыг нэртэй товчоор харуулна.

«Шалгах» эхлээд бодит хуваарилалтыг шалгана. Дараа нь тоон хариуг сонгож дахин шалгана. Зөв хуваарилалт болон зөв тоон хариу хоёулаа шаардагдана. Алдаа гарахад хийсэн ажлыг арилгахгүй. Тусламж эхлээд санаа өгч, дараагийн даралт бүрд зөвхөн нэг хөдөлгөөн үзүүлнэ.

Хүргэлт, галт тэрэгний хичээлд ногдвор болон үлдэгдлийг хоёуланг сонгоно. Эхний хичээлд тоолуур харагдана; дараа нь «Тоолуур харах» эсвэл «Туслаарай» дарж нээнэ. Зөв хуваарилсан ч тоон хариуг хүүхдийн өмнөөс бөглөхгүй.

Хөдөлгөөн ×2 тохиргоо хүлээлтийг багасгана. Хөдөлгөөн багасгах үед эцсийн байрлалыг шууд харуулна. Зөөгдөж буй зүйлийг дахин захиалах болон хөдөлгөөн дуусаагүй байхад шалгахаас бусад үйлдэл нээлттэй. Дараагийн зүйлээ сонгож хүргэлтийн дараалалд оруулж болно. Буцаах, дахин эхлэх, хичээл солиход хөдөлгөөнийг цуцалж, бодит хадгалсан байрлалаас дахин дүрслэнэ.

## Кодын бүтэц

- `src/lessons.ts` — бүх даалгаврын нэгдсэн өгөгдөл.
- `src/game.ts` — DOM/Three.js-ээс тусгаарласан reducer, шалгах логик.
- `src/storage.ts` — хувилбартай хадгалалт, эвдэрсэн өгөгдлийг сэргээх хамгаалалт.
- `src/Scene.tsx` — геометрээр бүтээсэн 3D амьтад, хоол, гэрэл, сүүдэр, pointer удирдлага.
- `src/ForestScene.tsx`, `src/forest.ts` — өртөө, хүргэлтийн талбай, ил суудал, сагс, алхах зам, touch/drag удирдлага.
- `src/rig.ts` — Three.js Bone үеүүдтэй дүр, сарвууны холболт, хоёр холбоостой хөлийн IK, алхалт, суух болон хөдөлгөөний төлөвүүд.
- `src/motion.ts` — тооцооллоос тусдаа харагдах хөдөлгөөний дараалал, секундээр тооцсон үеүүд.
- `src/WorldChooser.tsx`, `src/lessonCopy.ts` — гурван бүсийн сонголт, Монгол тайлбар.
- `src/App.tsx` — дэлгэц, хичээлийн дараалал, ахиц, тохиргоо.
- `src/audioCatalog.ts`, `src/narration.ts`, `src/audioPlayer.ts`, `src/speech.ts` — 52 бичлэгийн бүртгэл, нөхцөл, нэг ярианы тоглуулагч, дууны эффект.
- `src/webmcp.ts` — дэмждэг хөтөч дээр одоогийн талбайг зөвхөн унших нэмэлт хэрэгсэл.
- `tests/` — логик болон хөтчийн автомат шалгалтууд.
- `scripts/standalone.mjs` — код, CSS, дүрслэлийг нэг HTML-д багтаах угсралт; MP3 тусдаа `audio/` хавтастай.

## Хамаарлууд

React, React DOM, TypeScript, Three.js, Lucide React, Vite, esbuild. Шалгалтад Node test runner, tsx, Playwright ашигласан. Яг хувилбарууд `package-lock.json`-д түгжигдсэн. Дүрс, зураг, 3D загварын алсын таталт байхгүй.

## Дуу ба хүртээмж

Хэрэглэгчийн Чимэгээр хөрвүүлсэн `1.mp3`–`52.mp3` бичлэгийг тохирох үйлдэлтэй холбосон. Нэг л яриа тоглоно; давтан сонсох, дуу хаах, чанга сул тохируулах удирдлага болон тухайн бичлэгийн текст харагдана. Асуултад хүүхэд зөв хариулж шалгуулсны дараа батлах яриа тоглоно. Бичлэггүй үед бичгэн заавар үлдэнэ. Дууны эффект Web Audio-оор үүсэж, ярианы үед намсана. Зураглал болон нэмэлт бичлэг шаардлагатай хэсгүүдийг [AUDIO-COVERAGE.md](AUDIO-COVERAGE.md)-д жагсаасан.

Төхөөрөмжийн `prefers-reduced-motion` болон тоглоомын хөдөлгөөн багасгах тохиргоог хүндэтгэнэ. Шинэ бүсүүдэд утасны дүрслэлийн нягтралыг 1.35, сүүдрийг 512; компьютерт 1.6 / 1024 хүртэл хязгаарлана. Дүрслэлийг ойролцоогоор 30 fps шинэчилж, хөдөлгөөний явцыг өнгөрсөн секунд болон замын уртаар тооцно. Амжилтын хөдөлгөөн дараагийн алхмыг түгжихгүй.

## Шалгалт

`tests/game.test.ts` нь 6÷2, 7÷2, 8÷3, 9÷3, дутуу хуваарилалт 2,2+3, тэнцүү бус 4,3, 10 алимыг 2-оор бүлэглэх, тусгай хичээлийн 7→8 өөрчлөлт, тоон хариу, таамаг өөрчлөх, 1000 дараалсан шилжүүлэлт, буцаах/дахин эхлэх, хадгалалт болон бүх хичээл бодогдохыг шалгана.

Хөтчийн тестүүд компьютер, утасны хэмжээ, товших, чирэх, буруу газар тавих, хичээлийн бүтэн дараалал, ахиц сэргээх, гарын удирдлага, тохиргоог шалгана. Энэ нь бодит Android/iOS төхөөрөмжийн гүйцэтгэлийн хэмжилт биш. 52 MP3 бүгд хөтчөөр уншигдсан; ярианы агуулгыг сонсож тексттэй тулгаагүй. `tests/audio.test.ts` болон `tests/audio.spec.ts` нь асуултын завсарлага, нөхцөл, давтан сонсох, цуцлах, дууны алдаа, чанга сул болон дугааруудын тохирлыг шалгана.

`tests/forest.test.ts` шинэ 12 хичээл, эзэнтэй суудал, дутуу вагон, хүргэлтийн алдаа, хуучин ахиц шилжүүлэх, хөдөлгөөний дараалал цуцлах, сарвуунд бэхэлсэн алим, FPS-ээс үл хамаарах хугацаа, шулуун зам болон эргэлтийн тулсан хөлийг шалгана. `tests/forest.spec.ts` нь шинэ хоёр бүсийн бүтэн урсгал, үлдэгдэл, амьд хөдөлгөөний үеүүд, шилжүүлэх/буцаах, хөдөлгөөний дундуур дахин эхлэх, хичээл солих, 12÷3-ын ялгаатай нэгжүүдийг desktop болон touch хэмжээнд шалгана.

Хадгалалтын хувилбар 3 боловч `animal-picnic-v1` түлхүүрийг үргэлжлүүлэн хэрэглэнэ. Хуучин хувилбар 1, 2-ын хичээл, амжилт, дуу, хөдөлгөөний тохиргоог уншиж, шинэ асуултын үе болон ярианы чанга сул тохиргоог нэмж өгнө.

Дүрүүд нь энэ төсөлд зориулж кодоор бүтээсэн үе бүхий загварууд; гаднын татдаг киноны загвар, texture, motion-capture файл ашиглаагүй. Эх үүсвэрийн тайлбар `ASSETS.md`-д бий. Энэ хувилбар физикийн ерөнхий симуляц ашигладаггүй: чиглүүлсэн зам, хөлийн IK, эд зүйл барих холболтоор хөдөлгөөн үүсгэдэг.

WebMCP хэрэгслийн гэрээ, өгөгдөл, оролтын шалгалтыг unit тестээр шалгасан. Энэ орчинд бодит WebMCP дэмждэг хөтөч холбогдоогүй тул тухайн хөтөчтэй интеграцыг баталгаажуулаагүй.
